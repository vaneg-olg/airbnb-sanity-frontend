# Bookmark Feature - User Guide

## Getting Started

### Accessing Bookmarks
1. Click the **"♥ My Bookmarks"** button in the top navigation bar
2. Or navigate directly to `/bookmarks`

### Bookmarking a Property

**From the Home Page:**
1. Hover over a property card
2. Click the heart button (♥)
3. Select a folder to save it to
4. The heart will turn red, indicating it's bookmarked

**From Property Detail Page:**
1. Click the heart button (♥) next to the property title
2. Select a folder to save it to
3. The button will show "Bookmarked" status

### Managing Your Bookmarks

#### Creating a Folder
1. Go to your **Bookmarks** page
2. In the left sidebar, click **+ Create Folder**
3. Enter a folder name (e.g., "Dream Homes", "Beach Destinations")
4. Click **Create**
5. Your new folder appears in the folder list

#### Renaming a Folder
1. Go to your **Bookmarks** page
2. Hover over the folder you want to rename
3. Click the **✏️ (pencil)** icon
4. Enter the new folder name
5. Click **Save** or press Enter
6. Click **Cancel** to discard changes

#### Deleting a Folder
1. Go to your **Bookmarks** page
2. Hover over the folder you want to delete
3. Click the **🗑️ (trash)** icon
4. Confirm the deletion in the dialog
5. **Note:** All bookmarks in that folder are automatically moved to "All Bookmarks"
6. The "All Bookmarks" folder cannot be deleted

#### Moving Bookmarks Between Folders
1. Go to your **Bookmarks** page
2. Find the bookmark you want to move
3. Click **Move to...** button on the bookmark card
4. Select the destination folder
5. The bookmark is instantly moved to the new folder

#### Removing a Bookmark
**Method 1: From Home/Property Pages**
1. Click the heart button (♥) on the property
2. Click **Remove bookmark**

**Method 2: From Bookmarks Page**
1. Find the bookmark you want to remove
2. Click the **✕** button on the bookmark card
3. The bookmark is immediately removed

#### Viewing Bookmarks in a Folder
1. Go to your **Bookmarks** page
2. Click on any folder in the left sidebar
3. The bookmarks in that folder appear on the right
4. You'll see the folder name and bookmark count at the top

#### Going Back to a Bookmarked Property
1. Go to your **Bookmarks** page
2. Find the bookmark you want to view
3. Click on the property title or image
4. You'll be taken to the property's detail page

## Features

### Bookmark Information
Each bookmark displays:
- **Property Image** - Thumbnail image of the property
- **Property Title** - Clickable link to property details
- **Price** - Nightly price (e.g., "£150/per night")
- **Saved Date** - When you bookmarked it (e.g., "Saved January 1, 2024")

### Folder Organization
- **All Bookmarks** - Default folder, cannot be deleted
- **Custom Folders** - Create as many as you want
- **Bookmark Counter** - Shows number of bookmarks in each folder
- **Quick Selection** - Highlighted when selected

### Search and Navigation
- Bookmarks are displayed in a grid format
- Scroll through your bookmarks
- Click folder names to switch between categories
- Empty state provides helpful guidance

## Tips & Tricks

- Move bookmarks between folders as your preferences change

- Bookmarks are saved in your browser

- Consider browser sync features for cross-device access

## Troubleshooting

### Bookmarks Disappeared
**Cause:** Browser cache/localStorage was cleared
**Solution:** Bookmarks are stored locally. If you cleared browser data, they cannot be recovered. Start bookmarking again.

### Can't See New Folder
**Cause:** Page needs to refresh
**Solution:** The folder should appear immediately. Try refreshing the page if needed.

### Bookmark Didn't Save
**Cause:** localStorage might be disabled
**Solution:** Check that localStorage is enabled in your browser settings.

### Heart Icon Not Changing
**Cause:** Page cache issue
**Solution:** Try refreshing the page to see the updated status.

## Privacy & Data
- Bookmarks are stored **only in your browser**
- No data is sent to any server
- Your bookmarks are **completely private**
- Clearing browser data will delete all bookmarks
- No tracking or analytics on bookmarked properties
